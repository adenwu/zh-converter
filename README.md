# 繁簡轉換（台灣用語）

自用的繁簡轉換網頁。目標是取代目前在用的 [ifreesite 繁簡轉換](https://www.ifreesite.com/gbk-big5-gb2312-utf8.htm)，
只保留「繁簡轉換」功能，並修正它「簡轉繁」時常見的錯字問題。

## 需求

### 核心需求
1. **簡體 → 繁體（台灣用語）**：這是主要用途，轉換結果要符合台灣的用字與用語習慣。
2. **繁體 → 簡體**：附帶功能，有即可。
3. **只要繁簡轉換**：不需要原網站的其他功能（GBK/Big5 編碼轉換、火星文、注音等都不要）。

### 要解決的問題：一簡對多繁的錯誤轉換
原網站是「逐字」轉換，遇到一個簡體字對應多個繁體字時會轉錯。例如：

| 簡體 | 原網站轉出（錯） | 正確（台灣） |
|------|------------------|--------------|
| 复仇 | 覆仇 | 復仇 |
| 病症 | 病癥 | 病症 |
| 沉默 | 沈默 | 沉默 |

正確的做法是**以詞彙為單位**轉換（先比對詞組，再處理單字），而不是逐字替換。

### 台灣用語
除了字形，也要盡量轉成台灣慣用詞，例如：
- 软件 → 軟體、网络 → 網路、信息 → 資訊、视频 → 影片、打印机 → 印表機

## 目前的做法（初版）

- 純前端靜態網頁：`index.html` + `style.css` + `app.js`，直接用瀏覽器打開即可，不需要伺服器。
- 轉換引擎使用 [opencc-js](https://github.com/nk2028/opencc-js)（OpenCC 的 JavaScript 版本），從 CDN 載入：
  - 簡 → 繁：`from: 'cn', to: 'twp'`（台灣字形 + 台灣慣用詞）
  - 繁 → 簡：`from: 'twp', to: 'cn'`
  - OpenCC 是以詞典做「最長詞優先」比對，可以正確處理上面的 復仇 / 病症 / 沉默。
- **自訂詞典**：遇到 OpenCC 也轉錯的詞，可以在頁面上自己新增「錯誤 → 正確」的修正規則，存在瀏覽器的 localStorage，轉換後自動套用。
- 功能：輸入框、輸出框、方向切換、一鍵複製、清除、輸入時即時轉換。

## 檔案結構

```
zh-converter/
├── README.md   ← 本文件（需求與說明）
├── index.html  ← 頁面
├── style.css   ← 樣式
└── app.js      ← 轉換邏輯、自訂詞典
```

## 使用方式

用瀏覽器直接打開 `index.html`（需要連網載入 opencc-js）。
或在 VS Code 安裝 Live Server 擴充功能，對 `index.html` 按右鍵 → Open with Live Server。
